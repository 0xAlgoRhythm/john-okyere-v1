overview: "Built CredAxis as founding engineer — a decentralized transcript and credential verification marketplace connecting students, institutions, and employers. Institutions issue tamper-proof credentials on-chain via Upgradeable Beacons, students own and control access to their records via auto-bound embedded wallets, and employers verify them instantly."
problem: "Academic credential verification is slow, manual, and prone to fraud. Institutions rely on outdated systems, students have no ownership over their records, and employers waste time chasing verification from registrars."
whatIBuilt: "Designed and built the full product end-to-end. Built an on-chain credential registry using Upgradeable Beacons on Base Sepolia for massive gas savings, a Hono/Drizzle backend API with automated email workflows, a Next.js frontend with Dark Fintech aesthetics, and a built-in MCP server for AI agent interactions. Engineered a Hybrid State Architecture featuring Cohort Invite Codes, robust PDF Transcript Previews, and strict 1:1 wallet-to-institution registrar enforcement mapping."
challenges: "Architecting a multi-tenant system for universities while optimizing gas costs, which led to using the Upgradeable Beacon pattern (82% gas savings). Providing seamless UX for non-crypto natives by implementing Privy embedded wallets that auto-bind upon email authentication without manual steps, and abstracting mandatory wallet logins for Registrars via time-locked Email OTP approvals. Mitigating severe browser Main Thread freezing (INP latency) during high-volume array computations and blockchain hook initializations via asynchronous chunking and frontend list pagination."
outcome: "Shipped from concept to fully functional, live production build. Smart contracts securely deployed to Base Sepolia, backend API and MCP indexing services running flawlessly, and the web app live with seamless embedded wallet UX. The platform is highly optimized, effectively managing complex background Wagmi hooks and ensuring instantaneous UI feedback."
